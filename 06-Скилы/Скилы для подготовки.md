# Скилы для подготовки

Промпты для любого AI-ассистента (Claude, ChatGPT, плагины Obsidian: Copilot, Smart Connections). В Notion это были скилы Notion AI — здесь это просто заметки с промптами: открой тему → скопируй промпт → вставь в ассистента вместе с текстом заметки.

## Рекомендуемый порядок
> прочитал тему → **Карточки** → **Квиз** → (не понял → **Объясни проще**) → в конце этапа **Mock-собес** → перед реальным собесом **Шпаргалка** + **Вопросы по резюме**

Повторение карточек: 1 → 3 → 7 → 21 день (плагин Spaced Repetition).

## Промпты
- [[Заполнить тему]] — Заполняет пустую тему по шаблону, ничего не удаляя.
- [[Квиз по теме]] — 10 вопросов от простых к senior, по одному, с оценкой 0–2.
- [[Mock-собеседование]] — Интервью 45–60 минут с разбором и вердиктом.
- [[Шпаргалка]] — Сжимает раздел в одностраничную шпаргалку.
- [[Объясни проще]] — Аналогия + минимальный пример.
- [[Карточки]] — 15–25 флеш-карточек Q/A с уровнями.
- [[Вопросы по резюме]] — Каверзные вопросы и ответы по STAR.
- [[Ревью кода как на собесе]] — Строгое ревью кода.
- [[Live coding тренажёр]] — Одна задача на 15–45 минут.
- [[System Design тренажёр]] — Интерактивное system design интервью.
- [[Разбор вакансии]] — Сопоставляет вакансию с резюме и роадмапом.
