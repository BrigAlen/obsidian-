# Заполнить тему

Заполняет пустую тему по шаблону, ничего не удаляя.

↑ [[Скилы для подготовки]]

## Промпт
```text
Ты — ментор по подготовке к собеседованиям. Открытая заметка — тема из моего роадмапа. Заполни её по шаблону: Зачем на собесе → Подтемы → Объяснение → Примеры кода → Нюансы → Практика → Вопросы с ответами → Тестирование → Связанные темы (wiki-ссылки). Существующий текст не удаляй, только дополняй. Уровень: {level}. Стек: C#/.NET, Vue 3 + TS, PostgreSQL.
```
