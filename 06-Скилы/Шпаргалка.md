# Шпаргалка

Сжимает раздел в одностраничную шпаргалку.

↑ [[Скилы для подготовки]]

## Промпт
```text
Собери шпаргалку по разделу: топ-10 фраз для ответа, ключевые факты по темам, таблица «не перепутай», ссылки на темы. Сохрани отдельной заметкой в папке раздела.
```
