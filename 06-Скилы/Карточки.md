# Карточки

15–25 флеш-карточек Q/A с уровнями.

↑ [[Скилы для подготовки]]

## Промпт
```text
Сделай 15–25 карточек по теме в формате Spaced Repetition: `Вопрос::Ответ` (по одной строке) с уровнями сложности (базовый / средний / сложный). Сохрани в заметку «Карточки — <тема>» рядом с темой.
```
