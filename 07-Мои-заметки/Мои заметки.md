# Мои заметки

↑ [[00 Карта]]

Личные заметки, разборы, журнал собеседований. Создавайте их из шаблонов (см. [[Руководство]]), ставьте теги `my/...`, `topic/...`, `flag/...`.

## Как искать
- По тегу: `tag:#my/interview`, `tag:#flag/weak`
- Страницы тегов на сайте: `tags/my/note`, `tags/my/interview`, `tags/my/bug`, `tags/my/task`

## Разделы
- **Inbox** — сюда попадают новые заметки, разбирайте раз в неделю
- **Архив** — разобранное и неактуальное

```dataview
TABLE tags AS Теги, file.mtime AS Изменена
FROM "07-Мои-заметки"
WHERE file.name != "Мои заметки"
SORT file.mtime DESC
```
