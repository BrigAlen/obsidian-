> [!info] Зачем это на собесе
> Практичный вопрос: как отдать список на миллион записей и не убить БД.

> [!note] Переписано
> Страница в Notion была заготовкой, содержимое написано заново.

## Объяснение

```text
GET /orders?status=paid&createdFrom=2025-01-01&sort=-createdAt&limit=50&cursor=eyJ...
```

| Способ | Параметры | Плюсы | Минусы |
|---|---|---|---|
| Offset/limit | `page`, `pageSize` | прост, переход на страницу N | медленный на больших offset, дубли/пропуски при вставках |
| Cursor (keyset) | `cursor`, `limit` | быстрый и стабильный | нет произвольной страницы |

Ответ:

```json
{
  "items": [ ... ],
  "nextCursor": "eyJjcmVhdGVkQXQiOiIyMDI1...",
  "total": null
}
```

Правила:

- Ограничьте `limit` сверху (например, 100) и задайте значение по умолчанию.
- Сортировку разрешайте только по индексированным полям из белого списка (`sort=-createdAt,number`).
- Фильтры — простые query-параметры; сложные — отдельный `POST /orders/search`.
- `total` считайте только если он нужен: `COUNT(*)` дорог.
- Курсор — непрозрачная строка (Base64 от ключа сортировки + id), клиент не должен её разбирать.

## Нюансы и подводные камни

- Сортировка по неуникальному полю без tie-breaker (`id`) даёт нестабильные страницы.
- Динамический `ORDER BY` из query — риск инъекции: только белый список.
- Индекс должен соответствовать фильтру и сортировке (составной).
- Ссылки `next`/`prev` можно отдавать в заголовке `Link` или теле.
- Для экспортов используйте асинхронную выгрузку, а не гигантские страницы.

## Практика

1. Реализуйте keyset-пагинацию по `(createdAt, id)` и проверьте план `EXPLAIN`.
2. Добавьте белый список сортировок.
3. Сравните offset и cursor на 5 млн строк.

## Вопросы с ответами

> [!question]- Почему offset-пагинация плоха на больших данных?
> БД читает и отбрасывает первые N строк, время растёт линейно; при вставках возможны дубли.

> [!question]- Что такое cursor pagination?
> Пагинация по значению ключа сортировки последней записи, использующая индекс и не зависящая от смещения.

> [!question]- Как безопасно принять параметр сортировки?
> Сопоставить со словарём допустимых полей.
