## Объяснение

Семантические теги описывают **смысл** содержимого, а не вид.

| Тег | Назначение |
|---|---|
| `header`, `footer` | шапка/подвал страницы или секции |
| `nav` | основная навигация |
| `main` | основное содержимое (один на страницу) |
| `article` | самостоятельный блок (пост, карточка новости) |
| `section` | тематическая секция с заголовком |
| `aside` | второстепенное (сайдбар, врезка) |
| `h1–h6` | иерархия заголовков (один `h1`, без пропусков уровней) |
| `figure` / `figcaption` | иллюстрация с подписью |
| `time`, `address`, `mark`, `abbr` | смысловые вставки |
| `ul/ol/li`, `dl`, `table` | списки и таблицы (не для вёрстки) |
| `button`, `a` | действие и переход |

```html
<body>
  <header><nav aria-label="Основная"><a href="/">Главная</a></nav></header>
  <main>
    <article>
      <h1>Заголовок</h1>
      <p>Опубликовано <time datetime="2025-06-12">12 июня 2025</time></p>
    </article>
    <aside>Связанные материалы</aside>
  </main>
  <footer>© 2025</footer>
</body>
```

Выгоды: экранные читалки понимают структуру (landmarks), поисковики извлекают смысл, меньше CSS-классов, работает встроенное поведение (клавиатура, фокус).

## Нюансы и подводные камни

- `div` с `onclick` вместо `button` не фокусируется и не активируется клавишей — потеря доступности.
- `<a>` без `href` — не ссылка; переходы — `a`, действия — `button`.
- Пропуски уровней заголовков (`h1` → `h4`) ломают навигацию по структуре.
- `section` без заголовка — бессмысленный `div`.
- Таблицы для раскладки — устаревший подход.

## Практика

1. Перевёрстайте страницу на `div` в семантическую разметку.
2. Проверьте структуру заголовков расширением/DevTools Accessibility.
3. Найдите в проекте `div`-кнопки и замените на `button`.

## Вопросы с ответами

> [!question]- Зачем семантическая вёрстка?
> Доступность, SEO, читаемость кода и встроенное поведение элементов.

> [!question]- Чем `article` отличается от `section`?
> `article` — самодостаточный фрагмент, который имеет смысл отдельно; `section` — тематический раздел внутри страницы.

> [!question]- Сколько `h1` на странице?
> Как правило один — главный заголовок страницы.
