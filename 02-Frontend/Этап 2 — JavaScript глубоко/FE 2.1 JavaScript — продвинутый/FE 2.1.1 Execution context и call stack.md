## Объяснение

**Execution context (EC)** — среда, в которой выполняется код. Виды: глобальный, функциональный, `eval`.

Создание контекста в две фазы:

1. **Creation**: создаётся Lexical Environment (переменные, объявления функций), определяется `this`, подготавливается ссылка на внешнее окружение (scope chain). `var` инициализируются `undefined`, `let/const` — в TDZ, function declarations — целиком.
2. **Execution**: выполнение кода построчно, присвоение значений.

**Call stack** — стек контекстов: вызов функции кладёт контекст, возврат снимает. Единственный поток — один стек, поэтому синхронный тяжёлый код блокирует страницу.

```js
function a() { b(); }
function b() { c(); }
function c() { console.trace(); }
a();
// стек: global → a → b → c
```

Рекурсия без базового случая: `RangeError: Maximum call stack size exceeded`. JS не гарантирует оптимизацию хвостовой рекурсии (реализована только в Safari).

Свойства:

| Понятие | Смысл |
|---|---|
| Lexical Environment | таблица привязок + ссылка на внешнее окружение |
| Scope chain | цепочка окружений для поиска переменных |
| `this` binding | определяется при вызове (см. [[N:3ea3310486798128ae5ce7936d799a28]]) |
| Heap | память для объектов |
| Call stack | порядок вызовов; хранит примитивы и ссылки |

Асинхронный код не блокирует стек благодаря очереди задач и event loop (см. [[N:3ea33104867981b2b063f7aa36540971]]).

## Нюансы и подводные камни

- Глубокая рекурсия (обход большого дерева) → итеративный алгоритм с явным стеком.
- Долгие синхронные функции блокируют рендер и события.
- Ошибки содержат stack trace — читайте его снизу вверх.
- Замыкания хранят окружение в куче, а не в стеке.

## Практика

1. Нарисуйте call stack для цепочки вызовов и запишите порядок создания/удаления контекстов.
2. Вызовите переполнение стека и перепишите рекурсию в цикл.
3. Найдите блокирующую функцию в Performance.

## Вопросы с ответами

> [!question]- Что такое call stack?
> Стек активных контекстов выполнения; последний вызванный возвращает первым.

> [!question]- Что происходит на фазе creation?
> Создаются привязки переменных и функций, определяется `this` и scope chain до выполнения кода.
