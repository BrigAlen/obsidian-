# Дашборд

> [!info] Только для Obsidian
> Нужен плагин Dataview. На сайте эта страница не публикуется.

## Прогресс по разделам
```dataview
TABLE WITHOUT ID domain AS Раздел, length(rows) AS Всего, length(filter(rows, (r) => r.status = "done")) AS Готово, length(filter(rows, (r) => r.status = "in-progress")) AS В_работе
FROM ""
WHERE type = "topic"
GROUP BY domain
```

## Слабые места
```dataview
LIST
FROM #flag/weak
SORT file.name ASC
```

## Часто спрашивают (hot)
```dataview
LIST
FROM #flag/hot
SORT file.name ASC
```

## Пора повторить
```dataview
TABLE domain AS Раздел, next_review AS Когда
FROM ""
WHERE type = "topic" AND next_review AND next_review <= date(today)
SORT next_review ASC
```

## Помечено к повторению
```dataview
LIST
FROM #flag/review
```

## В работе
```dataview
LIST
FROM ""
WHERE type = "topic" AND status = "in-progress"
```

## Мои заметки: последние
```dataview
TABLE file.mtime AS Изменена, tags AS Теги
FROM "07-Мои-заметки"
WHERE file.name != "Мои заметки"
SORT file.mtime DESC
LIMIT 15
```
