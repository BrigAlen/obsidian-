Подробности по каждой задаче ниже. Порядок важен: следующие опираются на предыдущие.

## B1. Подключение бэкенда

Сайт остаётся статическим (Quartz), а рядом поднимается API, к которому обращается фронтенд.

- [ ] Выбрать стек API (учебный проект на C#/.NET 9 и PostgreSQL, в духе раздела [[FS Fullstack-практика|Fullstack-практика]])
- [ ] Определить схему данных: пользователи, темы, отметки, заметки
- [ ] Поднять API и БД (Docker Compose локально, затем хостинг)
- [ ] Настроить CORS между `brigalen.github.io` и API, HTTPS, переменные окружения
- [ ] Health-check, логи, миграции БД, CI для API
- [ ] Вынести идентификаторы тем в стабильный список (slug или `notion_id`), чтобы отметки не ломались при переименовании

## B2. Вход по логину и паролю

- [ ] Регистрация и вход по логину и паролю
- [ ] Хранение пароля только в виде хэша (Argon2id или bcrypt), соль, ограничение числа попыток входа
- [ ] Сессия или токены: короткоживущий access-токен и refresh-токен в httpOnly-cookie
- [ ] Выход, смена пароля, сброс пароля
- [ ] Защита API: проверка владельца данных на каждом запросе, rate limiting
- [ ] Форма входа на сайте, состояние «вошёл» в шапке

Критерий готовности: пользователь видит и меняет только свои данные.

## B3. Отметки о прохождении материала

- [ ] Кнопка «Изучено» / «В работе» на странице темы (статусы `todo`, `in-progress`, `done`)
- [ ] Сохранение отметки в API, подгрузка при открытии страницы
- [ ] Отметки на уровне раздела и этапа: считаются из тем
- [ ] Отметка отображается в боковом дереве (галочка у изученных тем)
- [ ] Повторение: дата последнего просмотра и дата следующего (как поля `reviewed` и `next_review`)

## B4. Текущий прогресс пользователя

- [ ] Страница «Мой прогресс»: всего тем, изучено, в работе, сколько чтения осталось
- [ ] Прогресс по доменам (Backend, Frontend, Базы данных, DevOps) и по этапам
- [ ] Полоса прогресса на страницах этапов и разделов
- [ ] Блок «Что читать дальше»: ближайшие неизученные темы с высоким приоритетом
- [ ] Заменить статическую страницу [[Прогресс]] персональной (для гостя оставить общую сводку)

## B5. Заметки по материалу

- [ ] Поле заметки на странице каждой темы (markdown, автосохранение)
- [ ] Заметки привязаны к теме и пользователю, хранятся в API
- [ ] Страница «Все мои заметки»: общий список по всем темам, у каждой заметки указана тема со ссылкой на неё
- [ ] Поиск по тексту заметок, фильтр по домену, этапу и тегам
- [ ] Сортировка: по дате изменения, по теме
- [ ] Экспорт заметок в markdown (чтобы можно было забрать в Obsidian)

## B6. Интеграция с Notion

Пользователь в личном кабинете подключает свой Notion и синхронизирует его с нашей вики.

- [ ] Подключение через официальный OAuth Notion (публичная интеграция), токен хранится на сервере в зашифрованном виде
- [ ] Выбор страницы или базы Notion, с которой идёт синхронизация
- [ ] Заметки по темам отправляются в Notion: одна страница на тему, заметки внутри
- [ ] Обратная синхронизация: изменения из Notion подтягиваются в заметки вики
- [ ] Правила конфликтов: что побеждает при правке в обоих местах (по дате изменения, с пометкой о конфликте)
- [ ] Ручной запуск синхронизации и статус последней (дата, ошибки)
- [ ] Отключение интеграции: отзыв токена и удаление связей
- [ ] Учесть лимиты API Notion (около 3 запросов в секунду) и очередь запросов

## Принятые решения

- Хостинг: Render (бесплатный тариф) и Neon (PostgreSQL), всё приложение в одном Docker-образе вместе с сайтом
- Регистрация только по приглашению, пароль сбрасывается вручную, почта не нужна
- К одной теме можно писать несколько заметок

## Одобрено, очередь после B1–B6

Предложения, которые вы одобрили. Каждая задача получает свой номер.

- [ ] **B7. Повторение по интервалам.** Тема после изучения возвращается в «Повторить» через 1, 3, 7, 21 день; на главной блок «Сегодня повторить». Без него изученное быстро забывается
- [ ] **B8. Режим собеседования.** Вопросы из тем по одному, ответ скрыт, самооценка «знал / не знал»; слабые темы поднимаются в приоритет
- [ ] **B9. Карточки из заметок.** Строка `вопрос::ответ` в заметке превращается в карточку для повторения
- [ ] **B10. Активность.** Календарь-тепловая карта дней занятий, серия дней подряд, недельная цель по темам или часам
- [ ] **B11. Избранное и закладки.** Пометить тему «вернуться позже» или «на собеседовании спрашивали»
- [ ] **B12. Сообщить об ошибке в теме.** Кнопка создаёт issue в GitHub с адресом страницы и цитатой
- [ ] **B13. Админ-панель.** Список пользователей, приглашения, сброс пароля, блокировка, счётчики
- [ ] **B14. Экспорт и импорт.** Скачать все свои заметки и прогресс одним файлом (markdown и JSON), загрузить обратно
- [ ] **B15. Офлайн (PWA).** Установка на телефон, чтение тем без интернета, отложенная отправка заметок
- [ ] **B16. Резервные копии.** Регулярный дамп базы, хранение вне Render; на бесплатном Neon это страховка от потери данных
- [ ] **B17. Аудит и безопасность.** Журнал входов, список активных сессий, выход на всех устройствах, двухфакторная защита (TOTP)
- [ ] **B18. Теги и цвета у заметок.** Быстрый фильтр в общем списке: «важное», «вопрос», «код»
- [ ] **B19. Поиск по своим заметкам и отметкам.** на странице «Мои заметки»
- [ ] **B20. Подготовка к конкретной вакансии.** Выбрать темы под описание вакансии и собрать план подготовки с прогрессом

## Готово

- **B1 Подключение бэкенда:** API на ASP.NET Core (.NET 10) и PostgreSQL в одном Docker-образе с сайтом, деплой на Render (Neon для базы), миграции при старте, CI с тестами и сборкой образа.
- **B2 Вход по логину и паролю:** регистрация по одноразовым приглашениям (ссылка и код с копированием), сессии в cookie, смена пароля, сброс и блокировка администратором, защита от перебора.
- **B3 Отметки о прохождении:** статусы «Не начато», «В работе», «Изучено» на странице темы, галочки в боковом дереве.
- **B5 Заметки по темам:** несколько заметок на тему, общий список по всем темам со ссылкой на тему, поиск по тексту.
- **Контент:** добавлены темы про TCP, аналоги MinIO и Redis, раздел «Поиск и специализированные БД», альтернативы брокерам, Nginx, CI и Terraform, Gateway API, service mesh, CNI, трейсинг, Aspire, Dapr и Orleans, современный CSS, WebAssembly, WebRTC.

Частично сделано и остаётся в очереди:
- **B4:** есть общий счётчик прогресса в кабинете; нет разбивки по доменам и этапам, блока «Что читать дальше», полосы прогресса на страницах этапов.
- **B13:** приглашения, сброс пароля и блокировка есть; нет счётчиков и журнала действий.
- **B19:** поиск по заметкам есть; нет фильтров по домену, этапу и тегам.
