# Руководство по vault

Как устроена вики и как в неё добавлять свои заметки.

## Принципы

- **Папки — только верхний уровень.** Раздел (Backend, Frontend, ...) → этап → тема. Глубже не вкладываем.
- **Навигация — через MOC** (Map of Content): страницы разделов и этапов, где темы собраны списком. Одна заметка может входить в несколько MOC.
- **Теги — для сквозных срезов**, а не для структуры: «что это за тема», «насколько срочно повторить».
- **Свойства (frontmatter)** — для статуса и дат: `status`, `reviewed`, `next_review`.
- Один файл — одна тема. Ссылайтесь `[[Название заметки]]` вместо копирования текста.

## Система тегов

Теги иерархические: `пространство/значение`. Пишутся латиницей, чтобы не путаться в раскладке.

| Пространство | Значения | Зачем |
|---|---|---|
| `domain/` | `backend`, `frontend`, `db`, `devops`, `fullstack` | к какому разделу относится |
| `stage/` | `1` … `9` | этап роадмапа |
| `level/` | `junior`, `middle`, `middle+`, `senior`, `final` | уровень вопросов |
| `topic/` | `http`, `docker`, `sql`, ... | сквозная тема, можно придумывать свои |
| `kind/` | `moc`, `section`, `stage`, `prompt`, `guide` | тип страницы |
| `flag/` | см. ниже | пометки для повторения |
| `my/` | `note`, `interview`, `task`, `bug` | ваши собственные заметки |

### Флаги

Флаги ставятся в `tags` заметки и работают как ярлыки для подготовки:

| Флаг | Значение |
|---|---|
| `flag/hot` | часто спрашивают на собеседованиях |
| `flag/weak` | слабое место, нужно подтянуть |
| `flag/review` | надо повторить в ближайшее время |
| `flag/practice` | нужна практика руками |
| `flag/todo` | тема пока не наполнена |

Пример: `tags: [domain/backend, stage/3, level/middle, topic/di, flag/hot, flag/weak]`.

Все заметки с тегом можно увидеть на странице тега (`tags/flag/hot`), в панели тегов Obsidian и в поиске: `tag:#flag/weak`.

### Статусы

Свойство `status`: `todo` → `in-progress` → `done`. Это не тег: по нему считается прогресс в `Дашборд`.

## Приоритет и время чтения

У каждой темы в свойствах есть `priority` (`must` / `should` / `nice`) и `time` (минуты чтения), а вверху страницы стоит плашка «Приоритет · Чтение · Уровень». Оглавления этапов и разделов показывают их таблицей с прогресс-баром, страница [[Прогресс]] собирает всё в общую картину.

| Приоритет | Как читать |
|---|---|
| `must` Обязательно | без этого не пройти собес на своём уровне |
| `should` Желательно | часто спрашивают, стоит знать |
| `nice` По желанию | расширяет кругозор, читать после основного |

Всё пересчитывается автоматически скриптом `site/meta.py` (запускается при сборке сайта). Вручную можно поменять только `priority` у темы, время посчитается по объёму текста.

## Свои заметки

1. Создайте заметку командой **Templates: Insert template** и выберите шаблон из `_templates`:
   - `Моя заметка` — произвольная заметка с тегами
   - `Собеседование` — журнал реального собеседования: вопросы, ответы, обратная связь
   - `Разбор ошибки` — разбор бага или инцидента
   - `Задача` — задача с решением
   - `Карточки` — карточки для повторения (`Вопрос::Ответ`)
2. Новые заметки по умолчанию попадают в `07-Мои-заметки/Inbox`.
3. Проставьте теги: минимум `my/...` и `topic/...`; при желании `flag/...`.
4. Свяжите заметку с темой: `[[BE 3.2 Dependency Injection]]` в тексте или в блоке «Связанные».
5. Разобранное перенесите из Inbox в `07-Мои-заметки/Архив` или оставьте как есть, MOC соберёт их по тегам.

> [!warning] Публичность
> Репозиторий публичный, и все заметки попадают на сайт. Чтобы заметка не публиковалась, добавьте в её frontmatter `draft: true`.

## Карточки и повторение

Плагин **Spaced Repetition**: в заметке пишите `#flashcards/backend` и строки вида `Вопрос::Ответ`. Повторение по схеме 1 → 3 → 7 → 21 день. Шаблон — `_templates/Карточки`.

## Дашборд

`Дашборд` (только в Obsidian, нужен плагин Dataview): прогресс по разделам, слабые места, что повторить, свежие заметки из Inbox.

## Бэклог

Планы развития сайта (бэкенд, вход по логину и паролю, отметки о прохождении, персональный прогресс, заметки по темам): [[Бэклог]].

## Рекомендуемые плагины

- **Dataview** — таблицы и списки по тегам и свойствам
- **Spaced Repetition** — карточки
- **Templates** (встроенный) — шаблоны из `_templates`
- **Obsidian Git** — автосинхронизация с GitHub
- **Iconize** — outline-иконки (Lucide) для папок и заметок
