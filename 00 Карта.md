# Developer

Route map для подготовки к собеседованиям: от фундамента до проектирования и production-эксплуатации.

> [!tip] Как пользоваться
> Проходите базовые этапы параллельно по Backend и базам данных, затем подключайте Frontend и DevOps. После ключевых блоков закрепляйте знания в сквозном проекте, а финальные этапы используйте для System Design, лидерства и собеседований.

## Разделы
- [[BE Backend|Backend]] — C#, .NET 9, ASP.NET Core, EF Core, gRPC, GraphQL, Kafka, микросервисы, observability.
- [[FE Frontend|Frontend]] — Vue 3 + Quasar + TypeScript, middle+/senior.
- [[DB Базы данных|Базы данных]] — SQL, PostgreSQL, ClickHouse, Redis, MongoDB, MinIO (S3), миграции, репликация и шардирование.
- [[DO DevOps|DevOps]] — Linux, Docker, CI/CD, Nginx, Kubernetes, Ansible, Terraform, observability, безопасность.
- [[FS Fullstack-практика|Fullstack-практика]] — сквозной production-проект
- [[AN Аналитика и PM|Аналитика и PM]] — вики для бизнес- и системных аналитиков и PM: API для чайников, Postman, SQL, требования, Agile, B2B.
- [[Мои заметки]] — личные заметки, журнал собеседований, разборы
- [[Руководство]] — как устроен vault, теги и флаги, шаблоны
- [[Прогресс]] — что изучено, сколько осталось, что читать дальше
- [[Дашборд]] — прогресс, слабые места, что повторить (Dataview)

> [!success] Рекомендуемый порядок (Fullstack с уклоном в Backend на C#)
> Backend 1–3 + БД 1–2 → Backend 4–5 + БД 3–5 → Frontend 1–6 в ускоренном режиме → DevOps 1–4 → Fullstack-практика → Backend 7–8 + БД 6–7 + Frontend 7–8 + DevOps 5–8 → финальная подготовка (этапы 9).
> Backend Этап 6 (Node.js/NestJS) — опциональный второй стек.


## Общий прогресс
```dataview
TABLE WITHOUT ID domain AS Раздел, length(rows) AS Всего, length(filter(rows, (r) => r.status = "done")) AS Готово, length(filter(rows, (r) => r.status = "in-progress")) AS В_работе
FROM ""
WHERE type = "topic"
GROUP BY domain
```

## Что повторить (пора по расписанию)
```dataview
TABLE domain AS Раздел, next_review AS Когда
FROM ""
WHERE type = "topic" AND next_review AND next_review <= date(today)
SORT next_review ASC
```

## В работе
```dataview
LIST
FROM ""
WHERE type = "topic" AND status = "in-progress"
```

Статусы темы (`status` в frontmatter): `todo` → `in-progress` → `done`.
